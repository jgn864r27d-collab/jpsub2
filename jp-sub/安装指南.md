# JpSub 云端构建 · 傻瓜安装指南

把编译交给云端的 Mac，你只需在网页上点几下，最后下载一个 `.dmg` 双击安装。**不用装 Xcode、不用碰终端。**

---

## 准备（2 分钟）

- 一个能上网的电脑。
- 一个 GitHub 账号（免费，没有就现场注册）。

---

## 第一步：注册 / 登录 GitHub

1. 打开 <https://github.com>。
2. 有账号就点 **Sign in** 登录；没有就点 **Sign up**，用邮箱注册一个（收个验证码即可）。

---

## 第二步：新建一个仓库

1. 登录后，点页面**右上角的 + 号** → **New repository**。
2. **Repository name** 填：`jpsub`。
3. 其他都保持默认（Public 即可），点底部绿色 **Create repository**。

---

## 第三步：上传工程文件

1. 创建成功后，页面中间找到 **uploading an existing file** 这几个字，点它。
2. **先让隐藏文件显示出来**（关键，别漏传）：
   - 在 Mac 上打开解压后的 `jp-sub` 文件夹。
   - 按键盘 **`Cmd + Shift + .`**（句号键），隐藏的 `.github` 文件夹就会显示出来。
3. 把 `jp-sub` 文件夹里的**全部内容**选中，拖进网页的上传区域。必须包含这些：
   - `Sources` 文件夹
   - **`.github` 文件夹**（里面是自动打包配置，漏了就不会自动构建）
   - `build.sh`、`Info.plist`
   - `AppIcon.png`、`AppIcon.icns`
   - 其余文件一起传即可
4. 等文件上传完，点页面底部绿色 **Commit changes**。

> 小提示：上传后检查一下，仓库里能看到 `.github` 文件夹才算传全了。

---

## 第四步：等云端自动编译

1. 点仓库上方的 **Actions** 标签页。
2. 能看到一条「构建 JpSub macOS 安装包」正在运行（黄色转圈）。
3. 等 **1–3 分钟**，变成 **绿色 ✓** 就是成功了。

> 如果变成 **红色 ✗**，点进去 → 点左侧 **build** → 把里面的日志（尤其 `error:` 开头的行）截图发我，我来修。

---

## 第五步：下载并安装

1. 点进那条**绿色 ✓** 的运行记录。
2. 拉到页面最下面 **Artifacts** 区域，点 **JpSub-macOS** 下载。
3. 下载的是一个 zip，解压后得到 **`JpSub.dmg`**。
4. **双击 `JpSub.dmg`**，会弹出一个小窗口，把 **JpSub 图标拖进旁边的 Applications（应用程序）文件夹**。
5. 完成。以后从「启动台」或「应用程序」里打开 JpSub 即可。

---

## 首次打开提示"无法验证开发者"怎么办

因为没有购买苹果开发者签名，第一次打开会被系统拦一下，这是正常的：

- **右键**点 JpSub 图标 → **打开** → 再点 **打开**；或
- 系统设置 → 隐私与安全性 → 找到 JpSub → 点「仍要打开」。

只需这一次，之后正常双击打开。

---

## 卡住了怎么办

- **Actions 里红色 ✗**：点进去看日志，截图发我。
- **找不到 Artifacts**：确认那条运行是绿色 ✓，且拉到了页面最底部。
- **其他任何提示**：把屏幕上的原文截图发我。
